# Blog hero images

Source: Unsplash. The Unsplash Licence permits free commercial use and does not
require attribution, but provenance is recorded here so the origin of every
image in this repository is traceable, and any future licence question can be
answered without guesswork.

Each file was fetched at 1200 by 630, the Open Graph ratio, so one file serves
as both the on page hero and the social preview.

Generated SVG covers (scripts/newsletter/cover.ts) remain the fallback for a post with
no photograph. They render correctly on the page but are poorly supported by
social scrapers, so a photograph is preferred for anything meant to be shared.
